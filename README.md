Ticket Triage with Claude is a command-line tool that reads customer support tickets and sorts them by urgency. For each ticket it picks a category (such as billing, bug or security), a severity, writes a one-sentence summary and a suggested reply, and flags whether a person needs to look at it. It can run offline using keyword rules, or use the Claude API for better accuracy. The model’s answer is checked against a strict format before it is used, and if the model fails or returns something invalid, the tool falls back to the rules and sends the ticket to a person. Security and urgent tickets always go to a person, no matter what the model says. Suggested replies are never sent automatically. The project is written in Python with no outside libraries, includes 13 automated tests, and the README describes how it could be deployed on AWS with API Gateway, SQS, Lambda and DynamoDB. That deployment is a design only and has not been built.
